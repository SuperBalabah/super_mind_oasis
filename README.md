# Super Mind Oasis (心靈綠洲 · 課題之森)

專為 iPhone PWA 與桌面設計的 3D 治癒系心靈養成遊戲。
將內心的焦慮、課題與困惑轉化為一粒種子；讓時間在背景陪伴它生長；當你跨過關卡時收穫它，凝結為屬於你一生的「年輪之書」。

---

## 🌟 核心特色

1. **頂級質感 3D 懸浮心靈綠洲 (Three.js)**
   - 360° 觸控軌道旋轉與雙指縮放，自帶物理減速阻尼手感。
   - 柔和的體積光、晨曦、暖陽黃昏、靜謐星夜與綿綿細雨四種氛圍切換。
   - 隨微風輕晃的枝葉、動態水波倒影、空中漂浮的光斑微塵與夜間螢火蟲。
2. **課題之樹生命週期 (Mind Garden System)**
   - **播種**：寫下當下的焦慮或課題，挑選專屬象徵樹種（勇氣之橡、通透之杏、沈思白樺、釋懷藍花楹）。
   - **靜默生長**：絕無「不登入就枯萎」的懲罰，隨現實時間推移自然生長。
   - **心境記錄**：隨時記錄進展與感悟，如同在樹幹刻下思緒年輪。
   - **頓悟收穫**：問題解決時寫下覆盤心得，大樹開花結果，凝結為永久收藏的年輪徽章。
3. **100% 離線純合成 Web Audio 療癒音效**
   - 免下載任何外部音效包，純算法合成 288Hz 空靈頌缽、清脆水滴、柔和微風與雨夜白噪音。
4. **全螢幕 iOS PWA 沉浸支援**
   - 支援加入 iPhone 主畫面，自動隱藏 Safari 網址列與工具列，適配瀏海與動態島安全區域。
   - 離線 Service Worker 快取，飛航模式照樣秒開。

## 📱 iPhone 連線遊玩指南

1. **同 Wi-Fi 連線**：
   - 請確保你的 iPhone 與此 ASUS 電腦連線至同一個 Wi-Fi 網絡。
2. **打開 Safari 瀏覽器**：
   - 在 iPhone 的 Safari 網址列中輸入：
     ```
     http://10.254.15.148:5173/
     ```
     *(或電腦上的 `http://localhost:5173/`)*
3. **加入主畫面（秒變獨立 App）**：
   - 點擊 Safari 底部的「**分享**」按鈕（帶箭頭的方框）。
   - 往下滑動找到並點擊「**加入主畫面 (Add to Home Screen)**」。
   - 點擊右上角「**新增**」。
4. **開始遊玩**：
   - iPhone 桌面上會出現「**Mind Oasis**」專屬圖示，點開即進入無瀏覽器邊框的全螢幕沉浸世界！
